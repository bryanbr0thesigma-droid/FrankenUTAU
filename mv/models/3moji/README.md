# 3moji models

These eight models come from the 3moji 3D emoji library by jeremytoys
(https://3moji.org, https://github.com/jeremytoys/3moji, commit 8ec8bed).
They're licensed under Creative Commons Attribution-ShareAlike 4.0 International (see
LICENSE.txt). The reanimation loads them unchanged and recolours and toon-shades them at
runtime (`../../src/re/models.js`).

| file | used for |
| --- | --- |
| television.glb | the TV shots (colour bars, the hand reaching out, the red TV) |
| raised_hand.glb | the hand reaching out of the TV |
| telephone_receiver.glb, mobile_phone.glb | the broken phones |
| hot_beverage.glb | the cup in the bridge |
| tearoff_calendar.glb | the tear-off calendar |
| package.glb | the box on bird legs |
| telephone.glb | (spare) |
