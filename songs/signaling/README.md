# Signaling (次元通信) — Adachi Rei × Corrupt-Chan cover

Original song: 次元通信 "Signaling" by AnythingBecomeMoe (feat. Hatsune Miku, Kasane Teto).
This cover: Adachi Rei sings Miku's part, Corrupt-Chan sings Teto's, both rendered with the
headless UTAU engine in `.claude/skills/utau/` from notes mapped off the original vocal.
The full mix (which contains the original instrumental) is not kept in the repo.

| File | What it is |
|---|---|
| `signaling-adachi-rei-vocal.wav` | Adachi Rei's vocal track alone |
| `signaling-corrupt-chan-vocal.wav` | Corrupt-Chan's vocal track alone |
| `corrupt-chan-3d/` | Corrupt-Chan 3D model for the music video (see its README) |

Credits: Adachi Rei by missile39. Corrupt-Chan by mono23 (non-commercial use only, no use with
AI-generated songs or images; her creator allowed this AI-assisted tuning with a person monitoring it).
Corrupt-Chan design from the 2D mockup by bryanbr0.
